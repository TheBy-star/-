# 森林小屋 · Forest Cabin（零依赖 3D 网页场景）

[![WebGL2](https://img.shields.io/badge/WebGL2-zero--dependency-2E6DA4)](#)
[![No CDN](https://img.shields.io/badge/CDN-not%20required-4E7C2A)](#)
[![Offline](https://img.shields.io/badge/offline-ready-C0504D)](#)

一个**完全零依赖、可离线运行**的 3D 森林小屋场景：小木屋、敞开的门、屋内陈设、门外长凳上睡觉的小狐狸、随风摆动的树与草、飞舞的萤火，以及一整套手写的电影感渲染管线。

> 打开 `index.html` 即可运行。不需要联网、不需要安装任何东西、不需要起服务器。

---

## 为什么不用 Three.js

不是不想用，而是**开发环境的网络策略阻断了所有 CDN**（jsdelivr / unpkg / cdnjs / esm.sh / npm registry 全部连接重置）。依赖 CDN 的页面在这台机器上会直接白屏。

于是改成**自己写一个精简的 WebGL2 渲染器**——顺带的好处是：所有素材都不能下载，只能程序生成，因此**零成本、无版权问题、完全离线**。

## 技术要点（全部手写实现）

| 模块 | 实现方式 |
| --- | --- |
| **渲染器** | 手写 WebGL2：VAO/VBO、实例化渲染、深度纹理阴影、HDR 帧缓冲 |
| **几何** | 全部程序化生成：圆柱（原木）、圆台、球、锥、长方体，带合并/批处理 |
| **材质** | GLSL 程序化着色：木纹、树皮、石纹、草地、沙土小径、砖石基础 |
| **光照** | 低角度暖阳主光 + 冷色天空散射 + 反方向冷补光 + 轮廓光（rim light） |
| **阴影** | 2048² 深度贴图，3×3 PCF 软阴影，树冠参与投影 |
| **空气透视** | 指数距离雾 + 高度雾，远景压暗偏冷，形成纵深 |
| **天空** | 全屏着色器：三段式渐变 + 流动云层 + 太阳核与光晕 |
| **体积光束** | 屏幕空间径向模糊（从太阳位置向后 34 次采样），无第三方后处理库 |
| **泛光** | 亮部提取 → 分离高斯模糊（横/纵两趟）→ 相加 |
| **色调映射** | ACES 近似曲线，HDR 先缩放进入曲线线性区间再映射 |
| **调色** | 青橙分离（Teal & Orange）+ S 曲线 + 暗角 + 胶片颗粒 |
| **动画** | 顶点着色器风吹摆动（草与树冠）、粒子精灵、相机缓慢漂移 |

### 场景内容

- **小木屋**：10 层错位堆叠的粗原木墙体、石砌基座、双坡屋顶（完整封檐）、实心山墙、门廊与台阶
- **门**：常开状态，绕合页旋转约 74°，带双面加强条与把手，从门口可见屋内空间
- **屋内**：木地板、天花板与横梁、石砌壁炉（带火光）、木桌与两把椅子、靠墙书架（含书籍）、床、地毯、烛台
- **小狐狸**：蜷缩睡在门廊长凳上，大尾巴绕过身体，闭合的眼缝
- **森林**：205 棵树（针叶锥形 + 阔叶球形），树干合批、树冠实例化
- **植被**：约 2800 簇草，实例化 + 顶点着色器风场
- **粒子**：306 个萤火与空气尘埃点精灵，加法混合

## 快速开始

```bash
# 直接双击 index.html 即可运行
# 或者起一个本地静态服务（可选）
python -m http.server 8000
```

### 操作

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 环视（松手 3.5 秒后自动回到运镜） |
| 滚轮 | 远近（3.2 ~ 34） |
| 空格 | 暂停 / 恢复相机漂移 |
| `1` `2` `3` `4` | 四个机位：门廊中景 / 全景林间 / 近景读书 / 低角屋脊 |
| `F` | 全屏 |
| `H` | 隐藏 / 显示界面 |
| `P` | 下载当前帧为 PNG |

### URL 参数

| 参数 | 作用 |
| --- | --- |
| `?ev=0.8` | 调整曝光（0.15 ~ 3.0，默认 1.0） |
| `?diag=1` | 显示诊断面板（FPS、GPU、绘制命令数、GL 错误） |
| `?nodiag=1` | 关闭默认开启的诊断面板 |
| `?nooutline=1` | 关闭描边通道 |
| `?noshadow=1` | 关闭阴影 |
| `?noinst=1` | 跳过实例化网格（排查用） |

## 自检与验证

项目附带两个 Node 脚本，用于在没有浏览器的情况下做静态验证：

```bash
# GLSL 静态审计：括号平衡、函数定义顺序、GLSL ES 3.0 保留字误用
node scripts/glsl-audit.js index.html

# WebGL2 模拟执行：在 Node 里跑一遍初始化和前两帧，捕获 API 误用
node scripts/mock-run.js index.html
```

预期输出：

```
GLSL AUDIT v2: PASS
=== 初始化脚本执行通过（无 JS 异常）===
关键 API 是否都被调用: 全部命中
```

浏览器内自检：打开 `selftest.html`，左侧显示 WebGL2 能力、GPU 型号与实时日志。

## 已知限制

- **需要 WebGL2**：Chrome / Edge / Firefox / Safari 新版均可
- 极端宽高比下地平线材质可能有轻微拉伸
- 静态验证覆盖 JS 语法、GLSL 结构与 WebGL API 调用，但**无法替代真实 GPU 上的着色器编译与视觉确认**
